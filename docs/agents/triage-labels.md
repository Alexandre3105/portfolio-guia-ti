# Triage Labels

As skills usam cinco papéis canônicos de triagem. Este arquivo mapeia cada papel para o valor usado no rastreador Markdown local.

| Papel da skill | Valor local | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa de avaliação do responsável |
| `needs-info` | `needs-info` | Aguarda informações de quem relatou |
| `ready-for-agent` | `ready-for-agent` | Está especificado e pode ser executado por um agente |
| `ready-for-human` | `ready-for-human` | Depende de implementação ou decisão humana |
| `wontfix` | `wontfix` | Não será executado |

Quando uma skill mencionar um papel de triagem, use o valor correspondente desta tabela sem criar sinônimos em português.
