# Fixar o destino do mapa

Type: grilling
Status: resolved
Blocked by: none

## Question

Qual resultado deve encerrar este mapa Wayfinder?

## Answer

O mapa termina quando existir clareza suficiente para produzir uma especificação completa do MVP e decompô-la em tickets de implementação, sem exigir novas escolhas de produto, conteúdo, UX, tecnologia, publicação ou qualidade do implementador.
